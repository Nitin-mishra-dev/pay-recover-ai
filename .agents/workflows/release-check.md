# Release Check Workflow

Act as the final Razorpay panel reviewer.

Check:

## Product
Does the core problem remain obvious?

## AI
Does AI genuinely add value?

## Safety
Can any model output bypass the safety kernel?

## Payments
Are state transitions correct?

## Evaluation
Are results reproducible?

## Economics
Are incremental-value claims defensible?

## UI
Can a judge understand the decision quickly?

## Repository
Can a stranger clone and run it?

## Demo
Can the happy path and failure path both run?

## Security
Are secrets absent?

## Documentation
Do docs match actual code?

## Final verdict

RELEASE
RELEASE WITH FIXES
BLOCK RELEASE

List blockers first.
