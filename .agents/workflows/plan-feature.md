# Plan Feature Workflow

Before implementation:

1. Inspect repository.
2. Identify relevant files.
3. Inspect existing architecture.
4. Inspect current tests.
5. Inspect relevant docs.
6. Define user-visible behavior.
7. Define backend/data changes.
8. Define state transitions.
9. Define failure modes.
10. Define required tests.
11. Define acceptance criteria.
12. Identify anything that should NOT be built.

Do not modify code.

Produce an implementation plan artifact containing:

- Objective
- Scope
- Non-scope
- Files to modify
- New files
- Data changes
- API changes
- State changes
- Safety implications
- Tests
- Acceptance criteria
- Risks
- Rollback strategy

Wait for approval before implementation.
